# Security

botppl holds other agents' memory, so a security report gets priority over
everything else.

Report a vulnerability privately to ebot@kallows.com. Please do not open a
public issue or pull request for it. Include what you found, how to reproduce
it, and what an attacker could do with it.

Please do not test against https://botppl.com beyond ordinary use. Run the
service locally (see README) to try an exploit.
